一、系统概述

论文信息智能提取系统是河北大学中医药信息学实验室开发的一款基于大语言模型（LLM）的纯前端网页工具。系统能够批量读取论文数据文件（从中国知网、万方等数据库导出的 Excel/CSV），通过调用 AI 大模型 API 自动提取论文中的关键信息（如研究主题、研究方法、创新点、主要结论等），并将结果导出为结构化的 Excel、CSV 或 JSON 文件。

核心特点

  • 纯前端运行：所有数据处理在浏览器本地完成，无需安装任何软件，无需后端服务器
  • 数据安全：论文数据和 API Key 仅存储在用户本地浏览器，不经过任何第三方服务器
  • 多服务商支持：支持 DeepSeek、OpenAI、通义千问（阿里云）、智谱AI 及自定义服务商
  • 智能字段识别：自动识别知网导出文件的常见列名（篇名、摘要、关键词等）
  • 批量高效处理：支持并发控制、暂停/继续、失败自动重试
  • 灵活配置：可自定义提取字段、提示词模板，支持预览和单条测试
  • 多格式导出：支持 Excel (.xlsx)、CSV、JSON 三种格式导出

系统工作流程

配置API → 上传数据 → 配置提取字段 → 执行提取 → 导出结果

二、系统环境要求与启动方式

环境要求

项目要求
浏览器Chrome 90+、Edge 90+、Firefox 90+、Safari 14+ 等现代浏览器
网络需要访问 CDN（加载 Vue3 和 SheetJS 库）以及所选 AI 服务商的 API
数据文件支持 .xlsx、.xls、.csv 格式，文件大小建议不超过 5MB
API Key需要至少一个支持的 AI 服务商的 API Key

启动方式

1 方式一：直接双击打开

直接双击 index.html 文件，系统将在默认浏览器中自动打开。

2 方式二：通过本地服务器启动（推荐）

在项目目录下打开终端/命令行，执行以下命令：

python -m http.server 8080

然后在浏览器中访问 http://localhost:8080。此方式可避免部分浏览器的文件安全限制。

提示
首次打开时页面需要从 CDN 加载 Vue3 和 SheetJS 库，请确保网络畅通。如果加载失败，页面会显示相应提示。

三、完整使用流程

系统顶部导航栏包含五个标签页，按照从左到右的顺序依次操作即可完成全部流程。

3.1 步骤一：配置API（API配置页）

这是使用系统的第一步，需要配置 AI 大模型的 API 连接信息。

1 选择服务商

在「服务商」下拉框中选择您要使用的 AI 服务商。系统已内置以下服务商的配置：

服务商默认模型列表推荐场景
DeepSeek（默认）deepseek-v4-pro, deepseek-v4-flash, deepseek-chat, deepseek-reasoner国内首选，性价比高，支持浏览器直连
OpenAIgpt-4o, gpt-4o-mini, gpt-4.1, gpt-4.1-mini, gpt-4.1-nano国际领先模型，需配置代理
通义千问qwen-max, qwen-plus, qwen-turbo, qwen-long阿里云模型，国内直连
智谱AIglm-4-plus, glm-4-air, glm-4, glm-4-flash智谱模型，国内直连
自定义用户自行添加兼容 OpenAI API 格式的任意服务商

选择服务商后，系统会自动填充对应的 Base URL 和默认模型。

2 填写API Key

在「API Key」输入框中粘贴您的 API 密钥。输入框默认以密码形式显示，点击「显示」按钮可查看输入内容。

如何获取API Key？
DeepSeek：访问 https://platform.deepseek.com/ 注册并创建 API Key
OpenAI：访问 https://platform.openai.com/api-keys
通义千问：访问 https://dashscope.console.aliyun.com/
智谱AI：访问 https://open.bigmodel.cn/
3 选择模型

在「模型」下拉框中选择要使用的具体模型。如果下拉列表中没有您需要的模型，可以在「自定义模型名」输入框中输入模型名称并按回车添加。

模型选择建议
  • 日常批量提取：推荐使用性价比高的模型，如 DeepSeek 的 deepseek-v4-flash 或 通义千问的 qwen-turbo
  • 复杂推理任务：推荐使用更强的模型，如 deepseek-reasoner 或 qwen-max
  • 大量数据处理：推荐使用便宜快速的模型以控制成本
4 调整高级参数
参数说明推荐值
并发数同时发送的API请求数量（1-10）3-5（根据API额度调整）
请求间隔每次请求之间的等待时间（毫秒）500ms（避免触发速率限制）
5 测试连接并保存

点击「测试连接」按钮，系统将发送一条简短消息验证 API 是否可用。测试成功后点击「保存配置」按钮，配置将保存到浏览器本地存储（localStorage），下次打开自动加载。

关于 OpenAI 的 CORS 限制
OpenAI 官方 API 可能存在跨域（CORS）限制，导致浏览器无法直接调用。解决方案：
1. 在 Base URL 中填写代理地址（如中转服务的URL）
2. 改用 DeepSeek、通义千问、智谱AI 等支持浏览器直连的国内服务商

3.2 步骤二：上传数据（数据上传页）

在此页面上传从数据库导出的论文数据文件。

1 上传文件

将文件拖拽到上传区域，或点击上传区域选择文件。支持以下格式：

  • .xlsx（Excel 2007+格式，推荐）
  • .xls（Excel 97-2003格式）
  • .csv（逗号分隔值格式）
2 查看数据预览

文件上传成功后，系统自动显示：

  • 数据统计：总行数、列数、文件名
  • 列名列表：所有列的名称
  • 已识别字段：系统自动识别的知网字段映射（如"篇名"→"标题"）
  • 数据预览表格：显示前10行数据
知网数据导出建议
在中国知网检索结果页面，勾选需要的论文，点击「导出」→「自定义导出」→ 选择包含篇名、摘要、关键词等字段 → 导出为 Excel 格式。

3.3 步骤三：配置提取字段与提示词（提取配置页）

这是系统的核心配置页面，分为左右两部分：左侧为字段配置，右侧为提示词编辑。

左侧：字段配置

1 使用预设模板（推荐）

点击「论文基础信息提取」或「文献综述分析」按钮，一键加载预设字段模板：

模板名称包含字段
论文基础信息提取研究主题、研究方法、数据集、主要结论、创新点、研究局限
文献综述分析所属领域、技术路线、对比基线方法、评价指标、实验结果、未来工作方向
2 自定义字段

也可以手动添加提取字段：

  • 字段名称（必填）：提取结果的列标题，如"研究主题"
  • 字段描述（必填）：告诉AI需要提取什么内容，如"研究的核心问题是什么"
  • 类型：文本、数字、列表、布尔值（影响AI输出格式提示）
  • 必填：勾选后AI会优先确保该字段有值

右侧：提示词编辑

3 System Prompt（系统提示词）

定义AI的角色和输出格式。点击「自动生成System Prompt」按钮，系统将根据已配置的字段自动生成包含 JSON 格式约束的系统提示词。您也可以手动修改。

4 User Prompt 模板（用户提示词模板）

定义每条数据发送给AI时的提示内容。使用 {{列名}} 插入数据变量，例如：

请提取以下论文的关键信息：
论文标题：{{篇名}}
摘要：{{摘要}}
关键词：{{关键词}}

系统会将 {{篇名}} 替换为每行数据中实际的论文标题。可以点击下方的变量标签快速插入列名。

5 预览与测试
  • 点击「预览提示词」：用第一行数据替换变量，展示将发送给AI的完整提示词
  • 点击「单条测试」：用第一行数据实际调用API，查看AI的返回结果，验证配置是否正确
建议
在开始批量提取前，先使用「单条测试」验证提取效果。如果结果不理想，可以调整提示词后重新测试。

3.4 步骤四：执行提取任务（任务执行页）

1 开始提取

确认 API 已配置、数据已上传、字段已设置后，点击「开始提取」按钮启动批量任务。系统将按照配置的并发数和间隔时间，逐条调用AI API处理每行数据。

2 监控进度

任务执行过程中，页面实时显示：

  • 进度条：已完成百分比
  • 当前处理：正在处理的论文标题
  • 成功/失败数：实时统计
  • 估算Token消耗：基于输入输出字符数的粗略估算
  • 预估剩余时间：根据已处理速度推算
3 任务控制
  • 暂停：点击「暂停」按钮暂停任务，再次点击「继续」恢复
  • 取消：点击「取消」按钮终止任务
4 失败处理

单条API调用失败时，系统会自动重试最多3次。如果仍然失败，该条数据会被标记为失败状态。系统每处理10条会自动保存中间结果到 sessionStorage，防止意外丢失。

3.5 步骤五：导出结果（结果导出页）

1 查看结果

任务完成后，在结果页面以表格形式展示所有提取结果：

  • 成功条目正常显示
  • 失败条目以红色背景高亮显示
  • 双击单元格可内联编辑，手动修正提取结果
  • 失败条目可点击「重试」按钮单独重新提取
2 导出设置
设置项选项说明
导出范围原始+提取字段 / 仅提取字段是否包含原始数据列
导出格式Excel (.xlsx) / CSV / JSON三种格式可选
3 导出文件

点击「导出文件」按钮，系统将生成对应格式的文件并自动下载。

五、高级功能说明

5.1 自定义模型名

在API配置页的「自定义模型名」输入框中输入模型名称并按回车，即可将自定义模型添加到模型下拉列表中。适用于使用服务商最新发布但尚未内置到系统中的模型。

5.2 知网字段智能识别

系统上传数据后，会自动扫描列名并识别以下常见字段：

识别关键词映射为
篇名、题名、标题、Title标题
摘要、Abstract摘要
关键词、Keywords关键词
作者、Author作者
来源、期刊、Journal、Source来源
发表时间、出版时间、年份、Year、Date时间
DOI、doiDOI

5.3 并发控制与速率限制

通过「并发数」和「请求间隔」参数控制API调用速率：

  • 并发数过高可能触发服务商的速率限制（HTTP 429错误）
  • 建议从小并发（2-3）开始，根据实际情况逐步提高
  • 如频繁出现429错误，请降低并发数或增加请求间隔

5.4 结果内联编辑

在结果表格中，双击任意单元格即可进入编辑模式，手动修正AI提取的结果。修改后会自动保存。

5.5 失败重试

  • 自动重试：每条数据失败后自动重试最多3次
  • 手动重试：在结果页面，对失败的条目点击「重试」按钮单独重新提取

5.6 清除数据

在结果页面底部点击「清除所有数据」按钮，将清除所有本地存储的配置和结果数据。

六、常见问题与故障排除

Q1：页面打开后显示"正在加载"不动？

可能是 CDN 资源加载失败。请检查网络连接，确保能访问 cdn.jsdelivr.net。刷新页面重试。

Q2：测试连接失败，提示"连接失败: Failed to fetch"？

  • 检查网络连接是否正常
  • 检查 Base URL 是否正确
  • 如果使用 OpenAI，可能需要配置代理地址（CORS限制）
  • 尝试使用 DeepSeek 等国内服务商

Q3：测试连接成功但批量提取全部失败？

  • 检查API账户余额是否充足
  • 检查是否触发速率限制（降低并发数、增加请求间隔）
  • 检查模型名称是否正确（不同服务商模型名称不同）

Q4：提取结果为空或JSON解析失败？

  • 使用「单条测试」查看AI实际返回的内容
  • 调整 System Prompt，强调"严格按照JSON格式输出"
  • 某些模型可能不适合JSON输出任务，尝试更换模型

Q5：上传文件后没有数据显示？

  • 确认文件格式为 .xlsx、.xls 或 .csv
  • 确认文件中确实包含数据（不是空文件）
  • 尝试用 Excel 打开文件确认数据正常，然后重新保存

Q6：如何控制API调用成本？

  • 选择性价比高的模型（如 deepseek-v4-flash、qwen-turbo）
  • 先用少量数据（5-10条）测试效果
  • 缩短提示词长度，减少不必要的字段
  • 降低并发数避免重复调用

Q7：提取效果不理想怎么办？

  • 优化字段描述，更具体地描述需要提取的内容
  • 修改 System Prompt，给出更明确的输出格式要求
  • 在 User Prompt 中提供示例
  • 尝试使用更强的模型（如 deepseek-v4-pro、qwen-max）

Q8：数据量很大（几百上千条）如何处理？

  • 分批上传处理，每批建议不超过200条
  • 使用较快的模型和适当的并发数
  • 系统会自动保存中间结果，即使意外中断也可恢复部分数据

七、安全与隐私说明

数据安全保障
  • 纯前端架构：系统所有代码运行在用户浏览器中，不经过任何第三方服务器
  • 本地存储：API Key 使用 Base64 编码存储在浏览器 localStorage，论文数据仅在浏览器内存中处理
  • API直连：数据仅发送至用户选择的AI服务商API，不经过任何中间环节
  • 一键清除：提供「清除所有数据」功能，可随时清除所有本地存储
注意事项
  • 请妥善保管您的API Key，不要分享给他人
  • 在公共电脑上使用后，请点击「清除所有数据」清除本地存储
  • API Key 使用 Base64 编码（非加密），仅提供基本保护
